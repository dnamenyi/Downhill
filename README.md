# Downhill Rush

A simple browser downhill mountain-bike racer inspired by Downhill Domination.
No build step: open `index.html` in a browser.

Controls: `→`/`D`/`Space` pedal, `↓`/`S` brake, `←`/`→` rotate in the air (land flips for a speed boost), `R` restart.
Race three AI riders to the finish line.
